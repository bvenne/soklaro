# Beitragen

Danke für dein Interesse. Erstelle für Änderungen einen fokussierten Branch, füge Tests hinzu und führe `npm run typecheck`, `npm test`, `npm run lint` und `npm run build` aus. Neue Netzwerkziele, SDKs oder lokale Speicherfelder benötigen eine Aktualisierung von Privacy-Dokumentation, Threat Model und Datenfluss.

Übersetzungen müssen dieselben Schlüssel wie `de` besitzen. Wetterbilder benötigen vor dem Merge Quelle, Urheber, Lizenz, Bearbeitung und dominante Farbe in `docs/assets.json`.
